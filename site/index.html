COBALT

A small design system, and the loop that keeps its code honest against its own spec.

A personal exploration built to test a spec-driven component pipeline: a PRD written as a checklist, and a loop that implements it against deterministic gates instead of a human reading for drift. The palette and form take Arne Jacobsen's AJ cutlery — the set that appeared in 2001: A Space Odyssey — as a reference point: what "futuristic" looked like in 1959 (brushed steel, tapered, no ornament) against what it looks like now.
